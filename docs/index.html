file-organizer

一个安全的命令行文件整理工具：先预览、后执行、可撤销，绝不覆盖你的任何文件。

GitHub 仓库 → 快速上手
~/Downloads — organize
$ organize ~/Downloads --apply   以下 5 个文件将被移动：   photo.jpg····· → Images/photo.jpg   report.pdf···· → Documents/report.pdf   movie.mp4····· → Videos/movie.mp4   song.mp3····· → Audio/song.mp3   backup.zip··· → Archives/backup.zip   ✔ 已移动 5/5 个文件，历史已记录，可用 --undo 撤销   $

🔒安全第一

默认只预览，加 --apply 才真正移动。不碰隐藏文件、子文件夹、程序自身。

♻️可撤销

每次整理都写入历史日志，--undo 一键完整还原，连空文件夹都帮你清理。

🛡️绝不覆盖

重名文件自动加序号（photo.png → photo_1.png），数据零丢失。

🎨自定义规则

--config rules.json 扩展分类，支持设计稿、开发文件等专属类别。

📅按日期归档

--by-date 按修改时间归档到 YYYY/MM/ 文件夹。

🧹清理空目录

--clean-empty 一键清掉空文件夹，含级联清理空父目录。

⚡ 快速上手

# 预览：看看会整理哪些文件（不会移动任何东西）
organize ~/Downloads

# 执行整理
organize ~/Downloads --apply

# 撤销最近一次整理
organize ~/Downloads --undo

# 按日期归档 / 自定义规则 / 清理空目录
organize ~/Downloads --by-date --apply
organize ~/Downloads --config rules.json --apply
organize ~/Downloads --clean-empty --apply
